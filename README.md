# ディレクション辞書β

Webディレクションの実務で使う用語・業務・考え方を、**1項目あたり1ページ**でまとめた辞書です。
一般社団法人ディレクションサポート協会（DiSA）が制作しています。

読みやすい版はこちら → https://disa-direction.notion.site/2bdd0f0a002680bf8bbed8cf008fee06

## 何が入っているか

全129項目。企画・プロデュースから、情報設計、制作進行、サービス運営、ツール、採用まで。

各ページはすべて同じ型で書かれています。

| 節 | 中身 |
|---|---|
| 10秒でわかる！要点まとめ | 忙しい人がここだけ読めば済むところ |
| 1. 概要 | その業務・用語が何か |
| 2. なぜ重要なのか | 現場で効いてくる理由 |
| 3. 実務のポイント | 具体的な進め方・つまずきどころ |
| 4. スキルアップのヒント | 次に何をやればいいか |

ファイル名の先頭の番号が、そのまま章立ての並び順です。

## 使い方

- **通しで読む**: `001` から順に追うと、案件の流れどおりに並んでいます
- **引く**: 困っている言葉でファイル名を検索してください
- **AIに読ませる**: Markdownなので、そのままChatGPTやClaudeに投げて質問できます

## 注意

- 記述には**制作現場の経験則**が含まれます。出典のある統計ではない数字も出てきます
- 法令・ツール・サービスの情報は **2026年8月時点**のものです。特に法改正とAI関連は動きが速いので、実務では最新を確認してください
- 内容の誤り・古さに気づいたら Issue で教えてもらえると助かります
